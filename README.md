# Amazon Homepage Clone 🛒

Hi, if anyone is reading this, this is my first project using HTML and CSS. When I started learning web development, I wanted to try recreating the Amazon homepage to see if I could do it or not.

Ik It is not an exact copy of Amazon, but I tried my best to recreate its layout and design using the basics of HTML and CSS.

## About the Project

I built this project to understand how a real website is structured and how different elements can be styled and arranged using CSS.

I tried recreating the homepage, starting from the navigation bar all the way down to the footer.

## Features

- Navigation bar with delivery location, search, language, account and cart sections
- Hero banner section
- Product category cards with images
- Hover effects on navigation items and links
- Footer with multiple columns and links
- Improved layout and responsive styling in the updated version

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Font Awesome

## Project Updates

This repository also contains the improvements I made after my initial attempt. I wanted to keep my original code and then update it as I learned more about HTML and CSS.

You can check the commit history to see how the project evolved from my first version to the improved version.

## How to Run

1. Download or clone this repository.
2. Keep `index.html`, `designing.css`, and the `images` folder in their respective locations.
3. Open `index.html` in your browser.

You can also use the Live Server extension in VS Code.

## Note

This is a personal learning project which I made as practice. It is a frontend recreation and does not include real shopping, payments, or account functionality.
